# SEFER — Control de versiones (local: Grok + usuario)

## Actual: v2.4.1-stable (2026-08-29)
**Nombre:** Pre-minificación + toolkit contenida

### Acceso oculto en la app
1. Escribe cualquier letra para abrir el **buscador de palabras** (o úsalo si ya está abierto).
2. Escribe exactamente: **`versionshistory`**
3. Se abre el historial de versiones (también vale: `historialversiones`, `seferversions`).
